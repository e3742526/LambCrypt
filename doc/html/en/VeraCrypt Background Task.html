Documentation Miscellaneous Background Task

Some illustrations and Windows instructions come from upstream VeraCrypt.

LambCrypt Background Task

When the main LambCrypt window is closed, the LambCrypt Background Task takes care of the following tasks/functions:

  1. Hot keys
  2. Auto-unmount (e.g., upon logoff, inadvertent host device removal, time-out, etc.)
  3. Auto-mount of favorite volumes
  4. Notifications (e.g., when damage to hidden volume is prevented)
  5. Tray icon

WARNING: If neither the LambCrypt Background Task nor LambCrypt is running, the above- mentioned tasks/functions are disabled.

The LambCrypt Background Task is actually the VeraCrypt.exe application, which continues running in the background after you close the main LambCrypt window. Whether it is running or not can be determined by looking at the system tray area. If you can see the LambCrypt icon there, then the LambCrypt Background Task is running. You can click the icon to open the main LambCrypt window. Right-click on the icon opens a popup menu with various LambCrypt-related functions.

You can shut down the Background Task at any time by right-clicking the LambCrypt tray icon and selecting Exit. If you need to disable the LambCrypt Background Task completely and permanently, select Settings -> Preferences and uncheck the option Enabled in the VeraCrypt Background Task area of the Preferences dialog window.
